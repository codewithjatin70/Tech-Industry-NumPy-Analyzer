# 📊 Tech Employment & Financial Analysis (NumPy)

## 📌 Project Overview
This project leverages the power of **NumPy** to analyze two decades (2000-2025) of tech industry data. The core focus is demonstrating how massive datasets can be processed efficiently using **Vectorized Operations** instead of traditional `for loops`, significantly reducing computation time.

## 🛠️ Key Technical Skills Demonstrated
* **Statistical Analysis:** Deep-dived into data distributions using Mean, Median, and Standard Deviation.
* **Z-Score Modeling:** Implemented the Z-Score formula to detect anomalies and volatility in corporate revenue.
* **Boolean Masking:** Engineered complex filters to isolate specific periods, such as the Post-2020 tech crisis.
* **Matrix Transformation:** Utilized Reshaping and Transposition to manipulate data for multi-dimensional analysis.

## 🔍 Major Insights from Data
1. **The 2023 Spike:** Analysis confirms that 2023 saw the most significant surge in tech industry layoffs in the 25-year history.
2. **Revenue Leaders:** Amazon and Apple emerged as the most resilient entities, showing consistent high-revenue growth regardless of market volatility.
3. **Hiring-Firing Ratio:** During the pandemic era, hiring rates disproportionately outpaced revenue growth, leading to the subsequent large-scale workforce corrections.

## 📂 Project Structure

* `tech_employment_2000_2025.csv`: The raw dataset used for analysis.
